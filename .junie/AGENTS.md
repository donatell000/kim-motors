# Проект: Kim Motors (kimmotors)

Одностраничный сайт для заказа автомобилей из Южной Кореи и Китая.

## Технологический стек
- **Framework**: Next.js 16 (App Router)
- **Styling**: CSS Modules (Tailwind 4 подключён, но используется только его базовый сброс стилей)
- **Animations**: Framer Motion
- **Language**: TypeScript

## Основные требования
1.  **SEO Оптимизация**: Сайт должен иметь высочайший уровень поисковой оптимизации.
    -   Использование семантических тегов HTML.
    -   Настройка метаданных (Title, Description, OpenGraph).
    -   Генерация `sitemap.xml` и `robots.txt`.
    -   Оптимизация скорости загрузки (Core Web Vitals).
2.  **Анимации**: Использование Framer Motion для плавных и современных переходов.
3.  **Адаптивность**: Полная поддержка мобильных устройств, планшетов и десктопов.
4.  **Контент**: Информация об услугах заказа авто из Кореи и Китая, преимущества, отзывы, контакты.

## Структура проекта
- `app/`: Основные компоненты и страницы (App Router).
- `public/`: Статические ресурсы (изображения, иконки).
- `components/`: секции страницы (по папке на секцию, стили в CSS Modules) и общие анимации (`reveal/`, `motion/`, `fade-image/`).
- `lib/`: данные компании (`site.ts`: домен, телефон, соцсети) и знак для иконок (`icon.ts`).

## Инструкции для агентов
- При добавлении новых секций на страницу всегда учитывайте иерархию заголовков (H1, H2, H3) для SEO.
- Все изображения должны иметь атрибуты `alt`.
- Используйте `next/image` для оптимизации изображений.
- Анимации не должны мешать доступности (accessibility) и производительности.
